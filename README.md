# Thiab R. Taha Professional Academic Website

This package contains a 13-page static academic website for GitHub Pages.

## Pages
Home, Biography, Education, Research, Leadership, Publications, Presentations,
Conferences, Honors, Editorial Work, Service, Grants, and Contact.

## Upload
Upload all files and the `assets` folder to the root of your GitHub Pages repository.
Keep `CNAME` in the root. It contains `thiabtaha.com`.

## Important customization
Open `contact.html` and replace the placeholder with the preferred professional email address.
Additional links such as Google Scholar, ORCID, LinkedIn, and the UGA profile can be added later.
